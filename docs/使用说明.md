# 使用说明 — ai2live

[English: usage.md](./usage.md)

面向本地开发与后续接入 ChatGPT / 本地 Codex 的端到端说明。

## 环境要求

- Node.js **≥ 20**
- pnpm **9.x**（仓库锁定 `pnpm@9.15.0`）

## 1. 安装与构建

```bash
git clone <repo-url> ai2live && cd ai2live
pnpm install
pnpm -r build
pnpm -r test
```

## 2. 示例资源

若 `examples/simple-character` 下缺少图层 PNG：

```bash
node examples/simple-character/generate-assets.mjs
```

## 3. 编译与校验（确定性管线）

```bash
pnpm --filter @ai2live/cli exec node dist/cli.js compile ../../examples/simple-character
pnpm --filter @ai2live/cli exec node dist/cli.js validate ../../examples/simple-character
```

或：

```bash
pnpm compile:example
pnpm validate:example
```

主要产物：`psd/character.psd`、`psd/import_manifest.json`、`validation/report.json`、`builds/autolive2d|psd2live/…`。

## 4. 里程碑命令

```bash
ai2live segment|occlusion|expressions|repair|downstream|unattended <项目目录>
```

构建后可用：

```bash
pnpm --filter @ai2live/cli exec node dist/cli.js <子命令> …
```

## 5. 模型提供方（规划 / 诊断）

本地可先用 **Grok**；之后可插拔 **OpenAI（ChatGPT）** 或 **本地 Codex**，无需改编译管线。

```bash
ai2live providers

# 无密钥干跑（CI / 冒烟）
export AI2LIVE_MODEL_DRY_RUN=1
ai2live agent plan ../../examples/simple-character
ai2live agent diagnose ../../examples/simple-character
```

输出：`validation/llm_plan.json`、`validation/llm_diagnosis.json`。

| 提供方 | 关键环境变量 | 说明 |
|--------|----------------|------|
| **grok**（默认） | `AI2LIVE_GROK_API_KEY` / `XAI_API_KEY`，`AI2LIVE_GROK_MODEL`（默认 `grok-2-latest`） | xAI OpenAI 兼容 API |
| **openai** | `OPENAI_API_KEY` / `AI2LIVE_OPENAI_API_KEY`，`AI2LIVE_OPENAI_MODEL`（默认 `gpt-4o`） | ChatGPT |
| **codex** | `AI2LIVE_CODEX_BIN`（默认 `codex`） | 本地 CLI，默认不打云端 |

切换：`export AI2LIVE_MODEL_PROVIDER=grok|openai|codex`。  
完整说明：[providers.md](./providers.md)。

## 6. 设计原则（简）

**Agent = 策略；程序 = 几何。**  
UUID、Z 序、PSD 命名、内容哈希、静态 QC 不交给 LLM。LEFT/RIGHT 始终是**角色自身**左右。

## CLI 一览

```text
ai2live compile|validate|segment|occlusion|expressions|repair|downstream|unattended <project>
ai2live providers
ai2live agent plan <project> [--provider grok|openai|codex]
ai2live agent diagnose <project> [--provider …]
```

更多架构见 [architecture.md](./architecture.md)、[DESIGN.md](./DESIGN.md)。
