# 使用说明 — ai2live

[English: usage.md](./usage.md)

面向本地开发与后续接入 ChatGPT / 本地 Codex 的端到端说明。

## 环境要求

- Node.js **≥ 20**
- pnpm **9.x**（仓库锁定 `pnpm@9.15.0`）

## 1. 安装与构建

```bash
git clone <repo-url> ai2live && cd ai2live
pnpm install
pnpm -r build
pnpm -r test
```

## 2. 示例资源

```bash
node examples/simple-character/generate-assets.mjs
```

## 3. 编译与校验

```bash
pnpm compile:example
pnpm validate:example
```

## 4. 里程碑命令

```bash
ai2live segment|occlusion|expressions|repair|downstream|unattended <项目目录>
```

## 5. 模型提供方（规划 / 诊断 / 返修）

```bash
ai2live providers
export AI2LIVE_MODEL_DRY_RUN=1
ai2live agent plan ../../examples/simple-character
ai2live agent diagnose ../../examples/simple-character
ai2live agent repair ../../examples/simple-character --apply-stub
```

| 提供方 | 关键环境变量 | 说明 |
|--------|----------------|------|
| **grok**（默认） | `AI2LIVE_GROK_API_KEY` / `XAI_API_KEY` | xAI OpenAI 兼容 |
| **openai** | `OPENAI_API_KEY` / `AI2LIVE_OPENAI_API_KEY` | ChatGPT + Images API |
| **codex** | `AI2LIVE_CODEX_BIN`、`AI2LIVE_CODEX_ARGS`、`AI2LIVE_CODEX_CWD`、`AI2LIVE_CODEX_TIMEOUT_MS` | 本地 CLI |

## 6. 图像编辑

```bash
export AI2LIVE_MODEL_DRY_RUN=1
ai2live image edit --prompt "修刘海" --input <png> --provider grok --project <项目>
```

可选 Python worker：见 `services/image-worker-python/README.md`，设置 `AI2LIVE_IMAGE_WORKER_URL`。

## 7. MCP

```bash
pnpm --filter @ai2live/mcp-server exec node dist/index.js
```

工具：`compile`、`validate`、`providers`、`agent_plan`。

## CLI 一览

```text
ai2live compile|validate|segment|occlusion|expressions|repair|downstream|unattended <project>
ai2live providers
ai2live agent plan|diagnose|repair <project> [--provider …]
ai2live image edit --prompt … --input … [--provider grok|openai]
```

完整配置：[providers.md](./providers.md)。
