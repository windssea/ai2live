# 使用说明 — ai2live

[English: usage.md](./usage.md)

## 一张设定图 → Live2D（推荐主路径）

只需一张角色设定/参考图，即可 **一键产出可下载的分层 PSD（主产物）**，并附带 AutoLive2d / psd2live 导入包，无需手写图层树。

**主产物：PSD 分层文件**（可直接导入 Photoshop / Live2D 相关工具）：

- `exports/<角色或项目名>_layers.psd`（推荐分发 / 下载）
- `psd/character.psd`（管线工作副本）
- `exports/import_manifest.json`（图层 UUID ↔ PSD 名对照）

### 控制台（推荐）

```bash
pnpm install && pnpm -r build
pnpm --filter @ai2live/studio dev
# 浏览器打开 http://127.0.0.1:5173
```

1. 点击 **导入设定图**（或填本地 PNG 路径）
2. 选择 provider（默认 grok）；无密钥时勾选 **dry-run**
3. 点击 **一键完成全部 / Run All**
4. 右侧 **产物** 面板下载 **PSD 分层文件（可导入 Live2D / Photoshop）**，并查看 AutoLive2d / psd2live 路径与 QC 状态

### CLI 一键

```bash
export AI2LIVE_MODEL_DRY_RUN=1   # 无密钥干跑；有 AI2LIVE_GROK_API_KEY 时可去掉以提升图层规划质量
ai2live run ./my-character --from-image ./design.png --dry-run --provider grok
# 或
pnpm ai2live -- run ./examples/simple-character --dry-run
```

产物（PSD 为第一优先交付物）：

- **`exports/<name>_layers.psd`** + `exports/import_manifest.json`（主产物，可下载）
- `psd/character.psd`（工作副本）
- `builds/autolive2d/`、`builds/psd2live/`（含 deep session）
- `validation/pipeline_report.json`

说明：dry-run / 无密钥时使用**确定性二次元半身模板**规划图层；配置 Grok/OpenAI 密钥后 LLM 可提出更贴合设定图的图层计划。

## 环境要求

- Node.js **≥ 20**
- pnpm **9.x**（仓库锁定 `pnpm@9.15.0`）

## 1. 安装与构建

```bash
git clone <repo-url> ai2live && cd ai2live
pnpm install
pnpm -r build
pnpm -r test
```

## 2. 示例资源

```bash
node examples/simple-character/generate-assets.mjs
```

## 3. 编译与校验（已有图层项目）

```bash
pnpm compile:example
pnpm validate:example
```

## 4. 统一管线命令

```bash
ai2live run <项目> [--from-image <png>] [--provider grok|openai|codex] [--dry-run]
ai2live run <项目> --skip-segment --skip-repair --json-events
ai2live pipeline <项目>   # run 的别名
ai2live unattended <项目> # 已改为薄封装，请优先用 run
```

其它里程碑命令：

```bash
ai2live segment <项目> [--feather 2] [--split-bilateral] [--debug]
ai2live occlusion|expressions|repair|downstream <项目目录>
ai2live doctor [--json]
```

## 5. 模型提供方

```bash
ai2live providers
export AI2LIVE_MODEL_DRY_RUN=1
ai2live agent plan ../../examples/simple-character
ai2live agent diagnose ../../examples/simple-character
ai2live agent repair ../../examples/simple-character --apply-stub
```

| 提供方 | 关键环境变量 | 说明 |
|--------|----------------|------|
| **grok**（默认） | `AI2LIVE_GROK_API_KEY` / `XAI_API_KEY` | xAI OpenAI 兼容 |
| **openai** | `OPENAI_API_KEY` / `AI2LIVE_OPENAI_API_KEY` | ChatGPT + Images API |
| **codex** | `AI2LIVE_CODEX_BIN` 等 | 本地 CLI |

## 6. 图像编辑 / MCP

见 [usage.md](./usage.md) 与 [providers.md](./providers.md)。

## CLI 一览

```text
ai2live run|pipeline <project> [--from-image] [--dry-run] [--provider] [--json-events]
ai2live compile|validate|segment|occlusion|expressions|repair|downstream|unattended <project>
ai2live doctor [--json]
ai2live providers
ai2live agent plan|diagnose|repair <project> [--provider …]
ai2live image edit --prompt … --input … [--provider grok|openai]
```

HTTP 超时：`AI2LIVE_HTTP_TIMEOUT_MS`（默认 60000）。环境变量模板：仓库根目录 `.env.example`。
